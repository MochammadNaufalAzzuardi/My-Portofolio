# Antigravity Skills & Design Systems Catalog

Semua skill dan sistem desain dari 5 repositori GitHub telah berhasil dipasang untuk project ini di bawah folder `.agents/`.

## 📦 Daftar Skill yang Terpasang (`.agents/skills/`)

### 1. Emil Kowalski Skills (`emilkowalski/skills`)
Fokus pada animasi UI, fluid motion, interaktivitas, dan polish:
- `animate`: Membangun animasi antarmuka dengan kurva timing, spring physics, dan durasi yang tepat.
- `animate-expo`: Animasi gesture dan sheet untuk aplikasi React Native / Expo.
- `animation-performance`: Audit performa motion, layout thrashing, dan optimasi GPU.
- `animation-vocabulary`: Glosarium istilah animasi web & interaksi.
- `apple-design`: Prinsip desain, kedalaman visual, dan motion ala Apple.
- `ask-sonner`: Pola toast notification dan micro-interaction.
- `choreograph`: Pengaturan sekuens dan timing beberapa elemen animasi sekaligus.
- `emil-design-eng`: Filosofi menyeluruh design engineering dan UI craftmanship.
- `gestures`: Drag, swipe, pan, dan gestur sentuh (touch interaction).
- `review-animations`: Review menyeluruh terhadap kode animasi sebelum rilis.
- `prototype`: Pembuatan prototipe UI cepat dan eksperimen interaksi.

### 2. Impeccable (`pbakaus/impeccable`)
Mencegah desain AI generik ("AI slop") dan menghasilkan UI kelas produksi:
- `impeccable`: Audit otomatis tata letak, hierarki kontras, font sizing, dan ritme desain. Dilengkapi script browser testing dan ratusan aturan anti-pattern desain.

### 3. Oil UI (`oil-oil/oil-ui`)
Eksplorasi estetika dan variasi tampilan antarmuka:
- `oil-ui`: Membantu mengeksplorasi berbagai arah desain yang kontras (side-by-side comparison) dan menyempurnakan UI berdasarkan screenshot browser.

### 4. UI/UX Pro Max (`nextlevelbuilder/ui-ux-pro-max-skill`)
Design-system intelligence engine:
- `ui-ux-pro-max`: Mesin pencari style UI berdasarkan jenis industri dan platform (SaaS, Mobile PWA, E-commerce).
- `design-system`: Pembuatan token warna, spacing, dan font secara terstruktur.
- `ui-styling`: Penerapan style tren (Glassmorphism, Bento Grid, Neumorphism, Minimalist, dll).
- `brand`: Pembuatan identitas visual dan brand guidelines.
- `banner-design`: Desain visual banner dan aset promosi.

### 5. Awesome DESIGN.md (`VoltAgent/awesome-design-md`)
Koleksi 80+ sistem desain siap pakai:
- Disimpan lengkap di: `.agents/awesome-design-md/` (termasuk Apple, Stripe, Linear, Vercel, Airbnb, Shopify, Figma, dll).
- Dilengkapi skill router: `awesome-design-md` untuk mencari dan menerapkan style token ke project.

---

## 🚀 Cara Menggunakannya di Antigravity
Skill ini otomatis aktif secara on-demand (*progressive disclosure*). Anda cukup mengetikkan prompt seperti:
- *"Gunakan skill `emil-design-eng` dan `animate` untuk menambahkan transisi halus pada modal jadwal klien."*
- *"Jalankan audit `impeccable` untuk memeriksa apakah tampilan halaman pesanan ada anti-pattern desain."*
- *"Gunakan skill `oil-ui` untuk membuat 3 opsi tampilan kalender booking MUA yang mobile-friendly."*
- *"Ambil inspirasi sistem desain dari `.agents/awesome-design-md/linear.app` untuk tema dark mode."*
