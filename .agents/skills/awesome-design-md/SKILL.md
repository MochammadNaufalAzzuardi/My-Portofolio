# Awesome DESIGN.md Library

This skill provides access to over 80+ curated, real-world `DESIGN.md` design system templates stored locally in:
`.agents/awesome-design-md/<brand>/DESIGN.md`

## Available Brand Design Systems
Popular brand styles available:
- **Productivity & Developer Tools**: `linear.app`, `vercel`, `stripe`, `figma`, `framer`, `raycast`, `supabase`, `warp`, `resend`, `notion`
- **Modern Tech & AI**: `claude`, `cursor`, `replicate`, `minimax`, `elevenlabs`, `runwayml`, `posthog`
- **Consumer & Lifestyle**: `apple`, `airbnb`, `spotify`, `pinterest`, `starbucks`, `nike`, `oura`
- **Fintech**: `revolut`, `wise`, `mercury`, `coinbase`, `mastercard`

## How to Apply a Brand Style
1. Read the corresponding `DESIGN.md` under `.agents/awesome-design-md/<brand>/DESIGN.md`.
2. Extract design tokens (palette, spacing scale, corner radius, typography, layout rhythm).
3. Apply those styling principles to the project's components, CSS/Tailwind configuration, or PWA layout.
4. If requested, copy or adapt the chosen `DESIGN.md` directly into the project root as `DESIGN.md`.
